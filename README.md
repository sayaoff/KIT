> [!IMPORTANT]
> KIT находится на стадии Alpha. Перед первой публичной стабильной версией проект проходит тестирование установщика, автозапуска и восстановления приложений на чистой Windows.

## Зачем нужен KIT

Перед игрой приходится закрывать лишние программы, запускать нужные инструменты, а после — восстанавливать рабочее окружение. KIT объединяет эти действия в **Kit** и выполняет их автоматически вокруг игровой сессии.

1. Вы выбираете установленный `cs2.exe`.
2. Создаёте Kit: что закрыть и что запустить вместе с игрой.
3. KIT замечает запуск CS2, применяет Kit и сворачивается в трей.
4. После закрытия игры KIT восстанавливает окружение и сохраняет сессию.

## Возможности Alpha 0.2

- Несколько Kits и безопасный неизменяемый **Vanilla Kit**.
- Общая **Библиотека приложений**: путь к программе хранится один раз и используется во всех Kits.
- Редактор **До игры → Во время игры → После игры**, показывающий полный жизненный цикл Kit.
- Для каждого приложения: обычное или принудительное закрытие, задержка и отдельное поведение после сессии.
- **Clean Mode** — полное завершение выбранных приложений, включая процессы в трее.
- **Launch Apps** — запуск выбранных приложений вместе с CS2.
- Автоматический **Restore** после игры и восстановление после аварийного завершения KIT.
- История сессий с длительностью, средним и пиковым CPU/RAM процесса CS2.
- Работа из системного трея и защита от запуска нескольких экземпляров.
- Опциональный автозапуск вместе с Windows без прав администратора.
- Русский и английский интерфейс, светлая/тёмная тема, спокойный/агрессивный стиль.
- Полностью локальное хранение без аккаунта, облака и телеметрии.

## Безопасность и прозрачность

KIT работает **вокруг игры**, а не внутри неё:

- не внедряет код и не устанавливает хуки;
- не читает память процесса;
- не изменяет файлы CS2;
- не автоматизирует игровой ввод;
- не взаимодействует с античитом;
- не отправляет телеметрию и не использует сеть;
- не требует постоянных прав администратора.

Исходный код опубликован для проверки. Полный перечень системных действий находится в [документе о прозрачности](docs/TRANSPARENCY.md). Для технической проверки доступны отдельные [инструкции сборки](docs/BUILDING.md) и [политика безопасности](SECURITY.md).

## Установка

1. Откройте [Releases](https://github.com/sayaoff/KIT/releases/latest).
2. Скачайте последний portable-архив для `win-x64`.
3. Полностью распакуйте архив и запустите `KIT.exe`.
4. На главной странице выберите `cs2.exe` из установленной папки Counter-Strike 2.

Установщик уже подготовлен в исходниках и будет добавлен к Release после отдельной проверки на чистой Windows.

Alpha пока не подписана коммерческим сертификатом, поэтому Microsoft SmartScreen может показать предупреждение для нового файла. Проверяйте адрес репозитория, SHA-256 из Release и при желании собирайте приложение самостоятельно.

## Быстрый старт

1. Откройте вкладку **Киты** и создайте новый Kit.
2. Добавьте приложения в **Чистый режим** и/или **Запуск приложений**.
3. Нажмите **Сохранить**, затем **Сделать активным**.
4. Запустите CS2 — KIT применит выбранные действия автоматически.
5. Закройте CS2 — KIT выполнит Restore и покажет результат сессии.

> [!WARNING]
> Clean Mode сначала запрашивает штатное закрытие приложения, ждёт две секунды, а затем завершает оставшийся фоновый процесс. Это нужно для tray-приложений вроде Telegram, но несохранённые данные могут быть потеряны. Добавляйте только те программы, которые действительно разрешаете закрывать.

## Дальше

Alpha 0.2 развивается по слоям. Foundation и Actions уже дают общую библиотеку приложений и управляемый жизненный цикл Before/During/After. Следующие этапы: расширенный мониторинг, Deck и безопасный import/export `.kit`.

FPS, injection, memory reading, изменение файлов игры, arbitrary scripts, Workshop/plugins, cloud и другие игры не входят в текущий scope.
